# Lab 7 E.3 — Bao04 hallway test

**Status: prepared; no real participant session has taken place.**
This worksheet supports E.3 (tutorial p.13): ask a classmate outside the team
to use the page for two minutes without explanation and record one thing that
surprised them. It is separate from Tân's H1 ten-minute homework test.

## Two-minute procedure

1. Start the API and UI. Record the exact commit and viewport below.
2. Invite one classmate outside the team. A participant code is sufficient;
   their name is not needed.
3. Give this neutral task: "Use this page to answer a study-related question
   of your choice."
4. Start a two-minute timer. Watch silently; do not point out the sidebar,
   examples, source labels or feedback controls. Record what actually happens,
   including any application error.
5. At the end ask, "What, if anything, surprised you?" Record their answer
   accurately. If there is no surprise, record that result rather than inventing one.
